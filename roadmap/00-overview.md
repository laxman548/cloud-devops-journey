# Cloud and DevOps Internship Roadmap

## Goal

Crack a ₹50k+/month Cloud, DevOps, or SRE internship by mid-2027.

## Current profile

- 3rd year, 1st semester
- 10 hours available per week
- Windows 11, Python 3.12, Git, GitHub, VS Code, and AWS account
- Main strengths to develop: Python automation, cloud fundamentals, and project building

## Learning approach

- Learn one small concept.
- Practice it immediately through commands, code, or a project.
- Write short notes in this repository.
- Commit work regularly to GitHub.
- Build separate repositories for portfolio projects.

## Phases

| Phase | Main topics | Main outcome |
|---|---|---|
| 1 | Linux, Git, Python automation | Python CLI and system automation fundamentals |
| 2 | AWS fundamentals and boto3 | AWS hands-on knowledge and automation scripts |
| 3 | Docker and GitHub Actions | Containerized application with CI pipeline |
| 4 | Terraform and AWS architecture | Infrastructure-as-Code capstone project |
| 5 | Resume, LinkedIn, applications, interview prep | Internship-ready portfolio and applications |

## Portfolio projects

1. `system-info-reporter` — A Python tool that generates system information reports.
2. `logkit` — A Python CLI that analyzes log files and generates JSON/CSV reports.
3. `aws-automation` — Python and boto3 tools for S3 and EC2 automation.
4. `terraform-aws-basics` — AWS resources provisioned through Terraform.
5. `aws-3tier-terraform` — A documented cloud infrastructure capstone.

## Progress rule

Each study session should produce at least one of these:

- A note
- A code improvement
- A test
- A Git commit
- A project README update
